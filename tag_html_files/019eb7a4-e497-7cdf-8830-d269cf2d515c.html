Remarques

  1. Un article de blog est une page web ayant obligatoirement une date de publication qui lui est associée.
  2. Un blog liste les articles par date de publication, de la plus récente à la plus ancienne (ordre antéchronologique).

Critères pour choisir le bon outil

  • Possibilité d'appliquer des tags et/ou des catégories aux articles.
  • Possibilité d'antidater un article de blog, c'est à dire pouvoir lui attribuer une date de publication dans le passé.
  • Possibilité de pouvoir écrire en markdown dans l'article.
  • Possibilité de pouvoir ajouter du code HTML dans l'article.
  • Possibilité de pouvoir rajouter du CSS et du JavaScript au blog, en particulier pour pouvoir formater l'affichage d'un langage de programmation ou de balisage.
