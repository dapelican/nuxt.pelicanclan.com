# Lexique anglais/français de la programmation informatique

Le monde de l'informatique est dominé par l'anglais. C'est parfois difficile (et chronophage) de trouver la traduction française correcte de certains termes. Voici un lexique qui pourra servir de référence.

| Anglais | Français |
| --- | --- |
| An expressions evaluates to the value...<br>An expression produces the value... | Une expression produit la valeur... |
| A statement | Une instruction |
| A function returns... | Une fonction renvoie... |
| The spread syntax | La syntaxe de décomposition |
| Hoisting | La remontée de code |
| The value is assigned to the variable | La valeur est assignée à la variable |
| Assignment operators | Opérateurs d'affectation<br>Opérateurs d'assignation |
| The code throws an exception/an error | Le code renvoie une exception/une erreur<br>Le code lève une exception/une erreur<br>Le code lance une exception/une erreur |
| String | Chaîne de caractères |
| Curly braces | Accolades |
| Brackets | Crochets |
| Factory function | |
| Constructor function | |
