
# Les 5 principes du design

1. Équilibrer les éléments pour avoir une symétrie apparente.
2. Aligner les éléments.
3. Doser la proximité des éléments pour rapprocher les éléments qui sont liés.
4. Répéter les éléments.
5. Contraster les couleurs.

Je vous recommande la vidéo [The 5 Design Principles (But in Web Design)](https://www.youtube.com/watch?v=A8bsrYqn0NQ) afin d’avoir une explication sur chacun de ces principes. Les principes 3 et 5 sont de loin les plus difficiles à mettre en oeuvre.
