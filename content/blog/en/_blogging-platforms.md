## Remarks

I've categorized the blogging platforms I would recommend in 3 different groups:

1. [The specialized platforms](#1). Blog management is their core feature and they mainly stick to it. Additonal features stay limited.
2. [The newsletter platforms](#2). These platforms handle newsletters natively. A visitor can also become a subscriber and receive each new blog post directly by email. The past issues of the newsletter are accessible as blog posts on an *archive* page or on the home page of the website.
3. [The website builders.](#3) These platforms have additional features to build a website beyond a blog. For instance, creating standalone pages, handling form submissions natively, selling content, selling access to content, and even handling newsletters natively.

## What is blogging?

Blogging is publishing content on the web in form of units called posts or articles. A website with such content is called a blog. Put differently, a blog is a collection of posts/articles.

## Management and hosting

Just like any other website, there are 2 fundamental concepts regarding blogs:

1. Software. A blog is usually managed with a piece of sofware called a content management system (CMS). A CMS provides a user-friendly interface to prevent the user(s) from altering directly the code of the blog to update it.
2. Hardware. From a technical point of view, a blog is a collection of code files and data that must be hosted on a web server.

Most blogging platforms provide both the software an the hosting. Sometimes however, they only provide the software. For example, [WordPress.org](https://wordpress.org/?utm_source=pelicanclan.com&utm_medium=article){target="_blank" rel="noopener noreferrer" class="text-primary"} or [Statamic](https://statamic.com/?utm_source=pelicanclan.com&utm_medium=article){target="_blank" rel="noopener noreferrer" class="text-primary"}. In this case, you need to install the software on a web server. The simplest way to do so is by renting a web server from a web hosting company.

## Fundamental features {#fundamental-features}

A blog has the following fundamental features:

- Each post has its own URL.
- Posts that belong to a same blog are automatically ordered by publication date, from the most recent to the less recent.
- Posts can have categories and/or tags. This allows thematic pages to list related posts.
- A blog can have an unlimited number of posts.
- A blog is an independent publication, that can have its own branding and a custom design. In particular:

  1. A blog can have its own domain name.
  2. A blog can get rid of any mention of the platform it uses.

## Criteria

Here are some possible criteria to choose between different blogging platforms:

- How good is the [technical SEO](/technical-seo) of the platform?
- How pleasant is the writing experience?
- How pleasant is the design (theme) **for you**? The simpler the design, the safer it is, especially if you aren't a designer. Design is very tricky and hard to do well.
- Is it possible to create additional pages?
- Is is possible to have natively newsletters?
- Is it possible to protect some blog posts by a paywall requiring a payment?
- Can you embed snippets of code? This is particularly necessary for developers.
